Algoritmia y Entornos (IDLE/Colab)

Términos Técnicos:

  • Algoritmo: Serie de pasos lógicos, finitos y no ambiguos ordenados secuencialmente para resolver un problema de ingeniería.
  • Pseudocódigo: Lenguaje intermedio entre el lenguaje natural humano y la sintaxis rígida de la máquina. Se usa para diseñar la lógica en papel antes de codificar.
  • Intérprete de Python: Software que lee tu script línea por línea y lo traduce a instrucciones de CPU en tiempo real, a diferencia de los compiladores clásicos (como en C) que traducen todo de golpe antes de ejecutar.

Lógica y Ejemplo Resuelto:

Problema: Un dron agrícola debe verificar si tiene suficiente batería antes de encender motores.

1. INICIO
2. LEER nivel_bateria desde sensor.
3. SI nivel_bateria > 20% ENTONCES
    4. IMPRIMIR "Sistemas listos para despegue"
5. FIN

5 Ejercicios Prácticos de la Vida Real:

  1. Diagrama de Flujo de Aterrizaje: Dibuja en papel (o software gráfico) el diagrama de flujo exhaustivo para el protocolo "Return to Home" (RTH) de un dron. Considera pasos como: checar GPS, elevarse a altitud segura, regresar a coordenadas, y descender.
  2. Pseudocódigo de Carga Útil: Escribe en lenguaje estructurado el algoritmo para calcular si un dron excede su peso máximo de despegue (MTOW). Debes solicitar el peso del marco, batería y la cámara.
  3. El Entorno Local (IDLE): Abre el IDLE de Python instalado en el laboratorio. Crea un nuevo archivo llamado telemetria_basica.py. Escribe la instrucción print("Enlace de telemetría establecido en puerto COM3"). Guarda y presiona F5 para observar cómo el intérprete ejecuta la orden en la consola física.
  4. El Entorno Cloud (Colab): Inicia sesión en Google Colab. Crea un cuaderno interactivo. En la primera celda, escribe la operación matemática para calcular el área de un círculo de reconocimiento (ej. 3.1416 * 50 * 50). Ejecuta la celda para que un servidor de Google procese la orden y te devuelva el resultado.
  5. Cacería de Errores de Sintaxis: En IDLE, intenta ejecutar intencionalmente print "Falla de motor" (omitiendo los paréntesis obligatorios en Python 3). Analiza el texto rojo del SyntaxError y documenta por qué la máquina requiere una sintaxis no ambigua.

Variables, Tipos de Datos y Memoria RAM

Términos Técnicos:

  • Variable: Un espacio reservado y etiquetado en la memoria RAM que sirve para almacenar datos temporales que el CPU procesará.
  • Tipado Dinámico: A diferencia de C (tipado estático rígido), Python infiere automáticamente si un dato es texto, entero o decimal. Una variable puede cambiar de tipo durante su vida útil.
  • Casteo (Casting): Obligar al intérprete a convertir un tipo de dato en otro (Ej. convertir el texto "100" en el número matemático 100 usando int()).

Lógica y Ejemplo Resuelto:

Tipos de datos fundamentales en sistemas de navegación:

# Asignación de memoria en Python
modelo_uav = "DJI Matrice 300"  # String (str) - Textos
motores = 4                   # Integer (int) - Enteros
frecuencia_ghz = 5.8          # Float - Decimales
camara_activa = True          # Boolean (bool) - Banderas Lógicas

5 Ejercicios Prácticos de la Vida Real:

  1. Declaración del Manifiesto de Vuelo: En un script de Colab, declara 4 variables que almacenen: el nombre del piloto (str), su número de licencia (int), la temperatura actual en grados Celsius (float) y si el permiso de vuelo está aprobado (bool). Imprímelas usando print().
  2. Análisis de RAM con type(): Crea una variable llamada coordenada = "19.432, -99.133". Utiliza la instrucción print(type(coordenada)) para averiguar cómo Python clasifica internamente este dato combinado.
  3. Registro de Telemetría Dinámica (Input): Utiliza la función input("Ingrese RPM del motor 1: ") para solicitar un dato al usuario en la terminal. Guarda este dato en una variable. Por defecto, input() recibe todo como String.
  4. Casteo Obligatorio para Matemáticas: Toma la variable del ejercicio anterior (String) y pásala por la función int() para convertirla a número entero. Intenta sumarle 500 para comprobar que el casteo matemático fue exitoso.
  5. Reporte con F-Strings: Formatea una cadena de texto inyectando variables directamente. Declara variables de `altitud` y `velocidad`. Genera la salida: print(f"ALERTA: El dron está volando a {altitud} metros con una velocidad de {velocidad} m/s.").

Operadores Lógicos y Aritméticos

Términos Técnicos:

  • Unidad Aritmético-Lógica (ALU): Circuito del procesador que resuelve todas las operaciones matemáticas y compuertas lógicas (AND/OR).
  • Operador Módulo (%): Calcula el residuo de una división. Extremadamente útil en programación para determinar si un valor es par o impar, o para crear rutinas alternadas.
  • Operadores Relacionales: Comparan dos datos (ej. ==, !=, >, <=) y siempre devuelven un valor Booleano (True o False).

Lógica y Ejemplo Resuelto:

Evaluación Combinada de Sensores de Seguridad: Un dron solo puede aterrizar automáticamente si está a menos de 5 metros de altura Y su velocidad horizontal es casi nula.

altitud = 3.5
vel_horizontal = 0.2
# Evalúa ambas condiciones con el operador AND lógico
permiso_aterrizaje = (altitud <= 5.0) and (vel_horizontal < 0.5)
print(f"Aterrizaje seguro autorizado: {permiso_aterrizaje}") # Salida: True

5 Ejercicios Prácticos de la Vida Real:

  1. Cálculo de Cobertura Agrícola: Un dron fumigador necesita mapear un terreno. Escribe un script que solicite al usuario la `base` y `altura` del terreno en metros (usando inputs casteados a float). Multiplícalos para obtener los metros cuadrados y calcula los litros de pesticida si gasta 1 litro por cada 50 metros cuadrados.
  2. Alternancia de Cámaras (Operador Módulo): Un sistema toma fotos cada segundo. Usa el operador módulo para saber si el "segundo actual" ingresado por el usuario es par o impar (segundo % 2 == 0). Imprime el resultado booleano. Esto se usaría para disparar la cámara térmica en segundos pares y la RGB en impares.
  3. Protocolo de Armado (Lógica AND): Declara dos variables booleanas: palanca_baja = True y boton_armado = True. Evalúa y muestra el resultado de usar el operador and. Ambas deben ser True para que el dron encienda motores.
  4. Redundancia de Sensores (Lógica OR): Tu dron tiene un sensor LiDAR frontal y uno infrarrojo. Declara ambos con distancias simuladas. Imprime el resultado lógico de distancia_lidar < 1.0 or distancia_ir < 1.0. Si al menos uno detecta algo a menos de 1 metro, el dron debe registrar peligro (True).
  5. Cálculo de Autonomía (División Entera): La batería total del dron otorga 137 minutos de vuelo bruto. Usa la división entera (137 // 60) para obtener las horas completas cerradas, y el módulo (137 % 60) para obtener los minutos sobrantes. Imprime: "Tiempo de vuelo: X horas y Y minutos".

Sintaxis Fundamental en Python vs C

Es crítico recordar que en este módulo migramos del lenguaje C a Python. Ya no verás puntos y comas (;) al final de cada línea, ni llaves ({}) para definir bloques. Python utiliza el salto de línea para saber que terminaste una orden, y confía ciegamente en una sintaxis limpia y minimalista. Cualquier carácter extra causará que el compilador rechace tu código.
