Estructura General de Programas y Datos en Python

Antes de escribir una sola línea de código, necesitamos aprender a pensar como una computadora. En estas primeras semanas construiremos los cimientos lógicos absolutos: cómo dividir problemas gigantes en pasos pequeños (Algoritmia), cómo guardar información en la memoria (Variables) y cómo interactuar con el usuario.

El Modelo IPO (Entrada-Proceso-Salida): Todo en la informática moderna funciona bajo esta arquitectura sagrada. Le damos datos al sistema (Input), el CPU realiza cálculos o toma decisiones (Process), y nos devuelve un resultado útil (Output).

Lógica Computacional: Algoritmos y Diagramas de Flujo

Glosario Técnico (Más explícito):

  • Algoritmo: Serie de pasos lógicos, finitos, definidos (sin ambigüedades) y ordenados, diseñados para resolver un problema. Es universal e independiente del lenguaje de programación. Finito significa que DEBE tener un final para evitar desbordar el CPU.
  • Pseudocódigo: Un puente escrito entre el lenguaje humano y el código de máquina. Es lógica pura redactada estructuradamente sin preocuparnos por la ortografía (sintaxis) estricta de un lenguaje como Python.
  • Diagrama de Flujo: Mapeo gráfico de un algoritmo. Usamos figuras geométricas estandarizadas internacionalmente (Óvalos = Inicio/Fin, Rombos = Decisiones bifurcadas, Rectángulos = Procesos u operaciones matemáticas, Paralelogramos = Entradas/Salidas).

Lógica Estructurada (Ejemplos Resueltos):

Observen cómo el problema se divide aplicando la arquitectura IPO: Entrada (Leer), Proceso (Decisión) y Salida (Imprimir).

Ejemplo 1: Cajero Automático

// PSEUDOCÓDIGO - SECUENCIA Y DECISIÓN
1. INICIO
2. LEER tarjeta y NIP
3. SI NIP es correcto ENTONCES:
4.    PEDIR monto_retiro
5.    SI saldo es suficiente ENTONCES:
6.       Entregar efectivo
7.       Actualizar saldo
8.    SINO:
9.       IMPRIMIR "Saldo insuficiente"
10. SINO:
11.    IMPRIMIR "NIP Incorrecto"
12. FIN
Diagrama de Flujo (Corregido):
graph TD A([INICIO]) --> B[/Leer Tarjeta y NIP/] B --> C{NIP Valido?} C -- NO --> D[/Error/] --> Z([FIN]) C -- SI --> E[/Pedir Monto/] E --> F{Saldo Suficiente?} F -- NO --> G[/Saldo Insuficiente/] --> Z F -- SI --> H[Entregar Efectivo] H --> I[Restar al Saldo] --> Z

Ejemplo 2: Despegue de Dron

// PSEUDOCÓDIGO - CONTROL DE HARDWARE
1. INICIO
2. Encender sistemas
3. LEER nivel_bateria
4. SI bateria_optima ENTONCES:
5.    Girar motores a 5000 RPM
6.    IMPRIMIR "Despegue exitoso"
7. SINO:
8.    Apagar motores de emergencia
9.    IMPRIMIR "Batería baja"
10. FIN

Diagrama de Flujo:
graph TD A([INICIO]) --> B[Encender Sistemas] B --> C[/Leer Bateria/] C --> D{Bateria Optima?} D -- NO --> E[Apagar Motores] E --> F[/Alarma Bateria/] --> Z([FIN]) D -- SI --> G[RPM a 5000] G --> H[/Despegue Ok/] --> Z

Entornos de Desarrollo: IDLE vs. Google Colab

Glosario Técnico:

  • Intérprete: A diferencia de lenguajes compilados (como C++), Python lee y ejecuta tu código línea por línea, traduciéndolo al instante. Esto facilita encontrar errores.
  • Sintaxis: Las reglas ortográficas obligatorias del lenguaje. En Python, olvidar dos puntos (`:`) o una sangría rompe el programa instantáneamente.
  • IDE (Entorno de Desarrollo Integrado): Un software que nos da un editor de texto inteligente, un depurador y una terminal. (Ej. Python IDLE, VS Code).

¿Cuándo usar qué?
Usaremos IDLE local cuando necesitemos acceder al disco duro físico de la PC o conectar hardware (Arduino/Drones vía puerto COM). Usaremos Google Colab para análisis de datos masivos y Machine Learning, aprovechando los procesadores gratuitos de Google en la nube.

  2. Análisis del Intérprete Interactivo (Shell): En la terminal de IDLE (no en el archivo de texto), escriban directamente 5 + 5 y den Enter. Observen cómo Python evalúa en tiempo real sin necesidad de compilar.

Tipos de Datos Nativos y Asignación Dinámica

Glosario Técnico:

  • Variable: Un espacio dinámico reservado en la memoria RAM (una caja con etiqueta) para guardar datos que el programa utilizará después.
  • Tipado Dinámico: En C o Java debes declarar qué tipo de dato es la variable (`int x = 5`). En Python no. Python es inteligente y deduce el tipo en tiempo de ejecución (`x = 5` automáticamente es entero).
  • Int, Float, Str, Bool: Integer (Enteros: 1, 5, -10). Float (Decimales o punto flotante: 3.14). String (Cadenas de texto: "Hola"). Boolean (Lógica binaria: True o False).

Sintaxis de Declaración en Python:

# Creando variables en memoria RAM
altura_dron = 120          # Tipo Integer (int)
velocidad = 15.5          # Tipo Float
piloto = "Alumno_01"     # Tipo String (str)
motores_encendidos = True # Tipo Boolean (bool)

# Verificando el tipo dinámico
print(type(velocidad)) # Retorna <class 'float'>

Operadores Aritméticos y Manipulación Matemática

Glosario Técnico:

  • Operador Módulo (`%`): Devuelve el *residuo* de una división matemática. Crucial en programación para saber si un número es par (residuo 0) o impar (residuo 1).
  • División Entera (`//`): Realiza una división pero corta o trunca los decimales, devolviendo solo la parte entera.
  • Precedencia de Operadores: El CPU obedece la jerarquía matemática estricta (PEMDAS): Paréntesis, Exponentes, Multiplicación/División, Suma/Resta.

Operaciones en Python:

x = 10
y = 3

# Operaciones Clave
exponente = x ** y    # 10 elevado a la 3 = 1000
division_normal = x / y  # Retorna 3.3333333333333335 (float)
division_entera = x // y # Retorna 3 (int)
residuo = x % y        # Retorna 1 (int)

Lógica de Máquina: Operadores Relacionales y Lógicos

Glosario Técnico:

  • Operador de Igualdad (`==`): CUIDADO: Un solo igual `=` sirve para asignar variables. Doble igual `==` es una pregunta al sistema: "¿Es esto exactamente igual a aquello?". Retorna un Booleano.
  • AND lógico: Obliga a que todas las condiciones conectadas sean Verdaderas para que el resultado general sea Verdadero.
  • OR lógico: Es permisivo. Basta con que solo una de las condiciones sea Verdadera para pasar la prueba.

Evaluación Binaria:

bateria = 80
sensor_obstaculo = False

# Condición AND (Doble candado de seguridad)
puede_avanzar = (bateria > 20) and (sensor_obstaculo == False)
print(puede_avanzar) # Retorna True. ¡Despegue Autorizado!

Interfaz con Usuario: Entrada y Salida Estándar

Glosario Técnico:

  • input(): Pausa la ejecución del programa y enciende el cursor, esperando a que el usuario teclee algo por teclado. OJO: Siempre, por defecto, captura todo como texto (String).
  • Casteo de Datos (Type Casting): Forzar a una variable a convertirse a otro tipo de dato en tiempo real, ej. usar `int()` para convertir texto a número y poder hacer matemáticas.
  • F-Strings (Interpolación): Una forma moderna y elegante en Python (versión 3.6+) para inyectar variables directamente dentro de un texto usando llaves `{}`.

El Modelo IPO en Código Real:

# 1. ENTRADA (Captura y Casteo a Entero)
edad_texto = input("Ingresa tu edad: ")
edad_numero = int(edad_texto) # Rompiendo el formato String

# 2. PROCESO (Cálculo)
anio_nacimiento = 2024 - edad_numero

# 3. SALIDA (F-String Moderna)
print(f"El usuario tiene {edad_numero} años y nació en {anio_nacimiento}.")
