Modularidad y Funciones

Un buen programador no repite código. Aprenderemos a encapsular la lógica en bloques reutilizables llamados Funciones usando la palabra clave reservada def.

Estructura de `def`

A diferencia de C, no tenemos que indicar el tipo de dato que retorna la función. Python lo maneja dinámicamente.

def calcular_distancia(vel, tiempo):
    """Calcula la distancia recorrida en línea recta."""
    distancia = vel * tiempo
    return distancia

# Llamando a la función (Paso de parámetros)
resultado = calcular_distancia(15, 3)
print(f"El dron recorrió {resultado} metros.")

Arquitectura Interna: Scope y Retornos de Tupla

Como ingenieros, debemos gestionar la memoria RAM de manera estricta. Las variables creadas dentro de un def son Variables Locales: existen solo mientras la función trabaja, luego son destruidas. Además, Python permite a las funciones romper las reglas de C, devolviendo múltiples variables agrupadas automáticamente en una Tupla.

Retorno Múltiple 
def obtener_coordenadas():
    latitud = 19.4326
    longitud = -99.1332
    return latitud, longitud

# 'Unpacking' (Desempaquetado mágico)
y, x = obtener_coordenadas()
print(f"Lat: {y}, Lng: {x}")
Contexto (Scope Local vs Global) 
bat_global = 100 # Nivel Global

def rutina_vuelo():
    consumo = 15 # Nivel Local
    print(bat_global - consumo)

rutina_vuelo()
print(consumo) # NameError! 
# 'consumo' ya fue purgado de la RAM.

Recursividad de Algoritmos

La recursividad ocurre cuando una función se llama a sí misma internamente. Es el pilar de algoritmos avanzados como la búsqueda de caminos para IA (Pathfinding) o fractales matemáticos. Regla de oro: Toda función recursiva debe incluir matemáticamente una Condición Base (Salida) para evitar sobrecargar la Pila de llamadas (Stack Overflow) con un bucle infinito.
