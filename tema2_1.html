Modularidad y Funciones Encapsuladas

Un buen ingeniero de software no repite código. Si vas a encender los motores del dron 50 veces en un mismo script, no escribes 50 veces las instrucciones para darles energía. Encapsulas esa lógica en un bloque reutilizable llamado Función usando la palabra clave def.

El Principio de "Caja Negra"

Crear una función es como fabricar un microchip personalizado. No importa cómo está soldado por dentro, lo importante es que al "llamarlo" e introducirle un dato (Argumento), el chip lo procese y expulse un resultado perfecto. Las funciones limpian el archivo principal y hacen que la arquitectura del sistema sea profesional.

Plan de Clases y Prácticas Reales

Selecciona la semana para desplegar la sintaxis de construcción de funciones, inyección de variables locales y los 5 retos de código en Python.

Definición y Llamadas a Funciones (Declaración `def`)

Términos Técnicos:

  • Definición vs. Invocación: Crear una función con def mi_funcion(): simplemente le enseña al intérprete de Python cómo funciona el bloque. No ejecuta nada. Para que corra el código, debes invocarla/llamarla escribiendo su nombre seguido de paréntesis: mi_funcion() en tu script principal.
  • DRY (Don't Repeat Yourself): Filosofía crítica en programación. No te repitas. Si copias y pegas el mismo código más de dos veces en un archivo, deberías haber hecho una función.

Lógica y Ejemplo Resuelto:

Rutina Pre-Vuelo Embebida: Agrupamos la carga de sensores en un bloque definido para limpiar el archivo maestro.

# Aquí definimos (fabricamos) la función
def arranque_motores():
    print("Escaneando hardware...")
    print("Voltaje OK. ESC calibrados.")
    print("Hélices girando.")

# El script real empieza aquí. Invocamos la función 2 veces.
arranque_motores()
# ... el dron hace otra cosa, se apaga ... y la reutilizamos sin volver a escribir el código
arranque_motores()

  2. Multi-Llamadas (Automatización): Basado en la función anterior, crea un bucle for i in range(5): y dentro de ese bucle llama a tu función. Observa cómo 3 líneas de código dentro de la función se convierten en 15 salidas impresas sin esfuerzo. Eso es poder modular.
  3. El Error de Compilación Lógico (Top-Down): Abre un cuaderno nuevo en Colab. En la primera línea llama a calibrar_brujula(). En la línea 5, declara la función def calibrar_brujula():. Ejecuta la celda. Analiza el NameError. La regla en Python es: El CPU lee de arriba hacia abajo. No puedes usar algo que aún no ha sido fabricado en la memoria.
  4. La Función Vacía (Stub) y palabra clave `pass`: Cuando estás diseñando la arquitectura de un software masivo, creas contenedores vacíos para programarlos luego. Escribe def algoritmo_ia_colisiones():. Si la dejas vacía, Python crashea por error de indentación. Soluciónalo escribiendo la palabra reservada pass dentro. Esto indica a Python "Ignora esto por ahora, el código está en construcción".
  5. Llamadas en Cascada (Anidadas): Crea dos funciones: checar_sistema() y iniciar_vuelo(). Dentro de iniciar_vuelo() llama a checar_sistema(). En tu script principal, solo necesitas llamar a iniciar_vuelo() para que se dispare una reacción en cadena.

Parámetros, Argumentos e Inyección de Datos

Términos Técnicos:

  • Parámetro: Una variable "comodín" o receptáculo que declaras entre los paréntesis al fabricar tu función (Ej. def mover(velocidad):). Sirve para que la función sea universal y trabaje con cualquier valor externo.
  • Argumento: Es el dato real, tangible, que le pasas o "inyectas" a la función al momento de llamarla. (Ej. mover(50)). El "50" viaja hacia el receptáculo "velocidad".
  • Argumentos por Defecto (Default): Permite darle un valor estándar a un parámetro por si el usuario se olvida de enviarlo. (Ej. def ascender(altura=10):).

Lógica y Ejemplo Resuelto:

Un algoritmo de navegación que recibe órdenes directas:

# 'eje_x' y 'eje_y' son PARÁMETROS. Esperan recibir datos.
def navegar_hacia(eje_x, eje_y):
    print(f"Ajustando pitch y roll. Trasladando a coordenadas X:{eje_x}, Y:{eje_y}.")

# El GPS lee valores. Los pasamos como ARGUMENTOS.
navegar_hacia(14.5, -2.1)
navegar_hacia(50.0, 10.0)

Luego llama a la función tres veces seguidas inyectando argumentos de texto diferentes (ej. "Edificio 1", "Torre Eléctrica", "Árbol"). Nota cómo la función se adapta a cada texto.
  2. Calculadora Aritmética Interna (Múltiples Parámetros): Define una función calc_velocidad(distancia, tiempo). Adentro, calcula la división e imprime "La velocidad resultante es X m/s". Llama a la función pasándole 100 de distancia y 5 de tiempo.
  3. Error Común - Faltan Parámetros: Crea una función que requiera 3 parámetros (ej. latitud, longitud, altitud). Llámala desde tu script pasándole solamente 2. Observa cómo Python explota con un TypeError: missing 1 required positional argument. Esto protege el software de hardware defectuoso que envía datos incompletos.
  4. Valores por Defecto (Seguros): Define una función para controlar la cámara: def tomar_foto(filtro="RGB", zoom=1):. Llama a la función usando parámetros vacíos tomar_foto(). Sentencia `return` y Aislamiento de Memoria RAM (Scope)

Términos Técnicos:

  • La instrucción return: Las funciones reales de ingeniería no usan print(). Su trabajo no es mostrar texto en pantalla, es masticar datos y "escupir" (retornar) un resultado utilizable que será atrapado por el script principal para continuar procesos matemáticos. La palabra return finaliza instantáneamente la función y devuelve el valor.
  • Ámbito Local (Local Scope): Cualquier variable creada dentro de una función nace y muere allí. El recolector de basura de Python purga esa memoria RAM en el momento en que la función termina su bloque de ejecución. Esto previene desbordamientos de memoria en vuelos largos.
  • Ámbito Global (Global Scope): Variables declaradas al aire libre en tu archivo. Viven durante toda la ejecución del script. Son accesibles para lectura dentro de cualquier función.

Lógica y Ejemplo Resuelto:

Matemática Invisible y Captura de Retornos Múltiples (Tuplas): A diferencia de C, en Python una función puede retornar varios valores simultáneamente separados por una coma.

def procesar_gps_crudo(trama_texto):
    # Simulando cálculos complejos...
    lat_pura = 19.43
    lon_pura = -99.13
    alt_pura = 2240.0
    # Regresamos 3 resultados como un misil hacia afuera
    return lat_pura, lon_pura, alt_pura

# CAPTURA: Fuera de la función, 'atrapamos' los datos devueltos
eje_x, eje_y, altitud = procesar_gps_crudo("data_antena")
print(f"Navegando hacia altitud: {altitud}")

Fuera de la función, ejecuta area_final = calcular_area(10, 20). Luego, realiza otra operación matemática con esa variable (ej. area_final * 2). Comprende por qué return permite que el dato siga existiendo y fluyendo en el software principal.
  2. Asesino Silencioso (Dead Code): Escribe una función sencilla que retorne un número con return 5.   3. Retorno Múltiple de Variables Físicas (Unpacking): Crea la función def leer_giroscopio():. Haz que retorne tres valores de balance ficticios: return 0.1, -0.5, 0.0. Afuera, absórbelos usando la sintaxis de desempaquetado automático: pitch, roll, yaw = leer_giroscopio().

Recursividad y Utilización de Librerías Nativas

Términos Técnicos:

  • Recursividad: Concepto avanzado. Es cuando una función, dentro de su bloque de código, se invoca a sí misma. Se usa ampliamente en algoritmos de Pathfinding (IA de búsqueda de rutas para drones y videojuegos) y estructuras de directorios.
  • Stack Overflow (Desbordamiento de Pila): Ocurre cuando un código recursivo no tiene límite, se llama a sí mismo miles de veces y agota toda la memoria RAM asignada al programa, colapsándolo a nivel de hardware.
  • Condición Base: Una condición (generalmente un IF al inicio del bloque recursivo) que, de cumplirse, obliga a la función a aplicar un return seco, deteniendo la recursividad e iniciando la cascada hacia atrás de resultados.
  • Import (Librerías): Cargar módulos de código previamente fabricados (por Python o por ti mismo) para no tener que reinventar funciones complejas como raíces cuadradas, fechas o cálculos trigonométricos (ej. import math).

Lógica y Ejemplo Resuelto:

Cuenta Regresiva Segura con Recursividad: El motor no usa bucle while, la función se devora a sí misma restando 1 cada vez hasta alcanzar su condición de salida.

def secuencia_auto_destruccion(segundos):
    # CONDICIÓN BASE - ¡Salva al CPU de morir!
    if segundos <= 0:
        print("PUM.")
        return
    
    print(f"Detonando en {segundos}...")
    # LLAMADA RECURSIVA: La función se inyecta su propio parámetro menos 1
    secuencia_auto_destruccion(segundos - 1)

# Activamos la espoleta enviando el '3' al chip.
secuencia_auto_destruccion(3)

5 Ejercicios Prácticos de la Vida Real:

  1. Forzando el Límite de la RAM: En el IDLE de Python, crea def loop_infinito(): print("Intentando conectar...") ; loop_infinito(). Ejecútala. Espera unos segundos y mira cómo la terminal vomita un `RecursionError: maximum recursion depth exceeded`. Acabas de experimentar el límite físico de pila de tu entorno de compilación.
  2. Recursividad Matemático (Factorial para Mapeo Combinatorio): Desarrolla la clásica función def factorial(n). Condición base: if n == 1: return 1. Recursividad: return n * factorial(n - 1). Calcula el factorial de 5 para saber de cuántas maneras diferentes el dron puede visitar 5 waypoints.
  3. Importando Inteligencia Nativa (Math Module): Un dron necesita saber la distancia radial desde su punto "Home" al objeto. Necesitarás el teorema de Pitágoras. Arriba del archivo pon import math. Crea una función normal calc_radio(x, y) que retorne la raíz cuadrada usando la librería C embebida de Python: return math.sqrt(x**2 + y**2).
  4. Optimización de Importación (from/import): A veces no quieres cargar un módulo entero con 100 funciones a tu pequeña placa de dron porque consume recursos. En lugar de import math, escribe from math import pi. Ahora, crea una función que calcule la circunferencia de tu hélice usando print(pi * diametro) sin tener que prefijar el nombre del módulo.
  5. Librerías Propias del Sistema de Archivos: Abre la carpeta donde estás trabajando. Crea un archivo Python puro llamado sensores.py. Adentro define def get_temperatura(): return 25. Crea otro archivo nuevo llamado main.py en la misma carpeta. Adentro escribe import sensores y luego imprime el resultado llamando a sensores.get_temperatura(). ¡Felicidades, acabas de modularizar un proyecto multi-archivo en Python!
