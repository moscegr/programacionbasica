Estructuras de Datos y Arquitectura de Errores

Dejamos los lenguajes estáticos de bajo nivel atrás. En C (o en lenguajes embebidos de placas electrónicas simples) usábamos arreglos limitados y jugábamos peligrosamente con punteros directos a la memoria que crasheaban constantemente. Python administra esto con una robustez de otro nivel mediante sus colecciones nativas maestras: Listas, Tuplas y Diccionarios. Además implementaremos la armadura final del código de producción: el bloque de Try/Except.

El paradigma del Recolector de Basura (Garbage Collector)

Para estas 5 semanas finales, debes entender que estas estructuras de datos (como las Listas que crecen o se achican solas) absorben mucha RAM dinámica. Cuando tu programa ya no las ocupa, Python detecta la inactividad y ejecuta un barrido automático de fondo que destruye el dato y libera la memoria física para otros subprocesos. Esto nos permite simular estructuras como Pilas de deshacer o Colas de tareas de servidores de manera hiper-eficiente.

Listas Dinámicas (Arrays Mutables)

Términos Técnicos:

  • Listas ([ ]): Secuencias dinámicas que agrupan múltiples datos (de distintos tipos) en una sola variable. Pueden estirarse y encogerse en plena ejecución del programa.
  • Mutabilidad: Capacidad técnica de un objeto (como la Lista) de poder modificar sus valores internos, expandirse o borrarse sin tener que crear un clon o asignar un nuevo bloque físico en el procesador.
  • Índice Base-Cero: Regla sagrada en ingeniería de software. Las máquinas y Python no cuentan desde el 1. El primer elemento de una lista vive en el cajón número `[0]`, el segundo en el `[1]`, etc.

Lógica y Ejemplo Resuelto:

Modificación en Tiempo de Ejecución (Runtime) de un Plan de Vuelo: Usamos métodos nativos para alterar la estructura de un Array Mutable.

# El script inicia con una lista de 2 puntos guardada en RAM
ruta_gps = ["Punto Inicial", "Sector de Exploración"]

# .append() inyecta un bloque al final dinámicamente
ruta_gps.append("Punto de Extracción") 

# Muta la memoria del cajón índice [0] reemplazando su texto original
ruta_gps[0] = "Base Militar Alpha" 

print(ruta_gps) 
# Salida: ['Base Militar Alpha', 'Sector de Exploración', 'Punto de Extracción']

Tuplas y Protección Inmutable

Términos Técnicos:

  • Tuplas (( )): Prima hermana de la Lista, pero diseñada bajo una arquitectura de "Solo Lectura". Se fabrican una vez y quedan selladas y comprimidas en la RAM usando paréntesis ordinarios. Son mucho más ligeras y rápidas de procesar que las listas.
  • Inmutabilidad: Bloqueo de escritura (Read-Only). Condición de seguridad a nivel kernel que impide a cualquier agente (ya sea un bug en tu propio código, un hackeo o un ruido de radiofrecuencia) alterar los datos sellados internamente en la tupla.
  • Unpacking (Desempaquetado): Mecánica sintáctica hiper-eficiente de Python para desarmar los datos encapsulados dentro de una Tupla y asignarlos instantáneamente a variables separadas en una sola línea.

Lógica y Ejemplo Resuelto:

Coordenadas Base Críticas (Blindaje de Memoria): El punto de retorno a casa (Return to Home) jamás debe poder editarse en vuelo, así evitamos accidentes fatales si un bug intenta sobrescribirlo (como pasaría si usamos Listas mutables).

# Tupla de coordenada fija fabricada con paréntesis
home_gps = (19.432, -99.133)

# UNPACKING: Asigna índice 0 a 'lat' y el 1 a 'lon' simultáneamente
lat, lon = home_gps
print(f"Latitud bloqueada: {lat}. Longitud de extracción: {lon}")

# SIMULACRO DE HACKEO O FALLA CRÍTICA
home_gps[0] = 20.5  # Python detiene el programa disparando un TypeError protector

Diccionarios (Mapeo por Claves) y Formato JSON

Términos Técnicos:

  • Pares Clave-Valor (Key/Value Mapping): Un diccionario de Python no usa cajones numéricos aburridos como [0], [1]. Usa etiquetas (llaves o Keys) como si fueran identificadores (ej. "bateria", "piloto"). Cuando pides el dato a través de la etiqueta, te devuelve su valor. Son la base de las bases de datos "NoSQL".
  • JSON (JavaScript Object Notation): El formato universal de internet mediante el cual los servidores de todo el planeta, API REST y satélites de telemetría transmiten datos serializados de texto plano. Un JSON es, en el 99% de las ocasiones lógicas, un mega Diccionario de Python disfrazado.
  • Hash Table: El mecanismo matemático interno que hace que buscar "temperatura" en un diccionario de 1 millón de registros sea casi instantáneo O(1), en lugar de tener que recorrer lista por lista buscando la palabra.

Lógica y Ejemplo Resuelto:

Modelo de Objeto de Software para Aeronave (Telemetría de Carga):

# Estructura del Diccionario con llaves (strings) y valores dinámicos
dron_db = {
    "ID_serie": "MX-DRN-001",
    "bateria_porcentaje": 85,
    "sensores_activos": True
}

# Agregar nueva etiqueta (llave) en pleno vuelo por descubrimiento
dron_db["mision_actual"] = "Mapeo Topográfico" 

# Actualizando el valor hash existente
dron_db["bateria_porcentaje"] -= 5  # Baja la batería a 80

print(dron_db["mision_actual"]) # Salida directa: Mapeo Topográfico

Comportamiento Físico de Memoria: Pilas (LIFO) y Colas (FIFO)

Términos Técnicos:

  • LIFO (Last In, First Out): Modelo "Pila" (Stack) en ingeniería. Imagina platos apilados. El último dato que metes a la lista es el único que puedes sacar primero. Clásico para el botón "Deshacer" (Undo) de un editor de texto o el tracking de navegación para retroceder paso por paso en el menú de carpetas.
  • FIFO (First In, First Out): Modelo "Cola" (Queue). Imagina una fila del supermercado. El primer archivo o comando que llega, es el primero que debe procesarse. La arquitectura principal para servidores web o el búfer de comandos de vuelo a distancia.
  • Deque (Double Ended Queue): Una estructura supervitaminada de Python (importada de la librería estándar `collections`). Mientras que sacar el primer elemento de una Lista normal es increíblemente lento porque el CPU tiene que mover el resto de elementos hacia la izquierda, el deque permite sacar e insertar datos instantáneamente O(1) desde ambos extremos del array físico.

Lógica y Ejemplo Resuelto:

Cola de procesamiento de tareas FIFO para Ground Station: Evitamos que las órdenes de vuelo se pierdan encolándolas a alta velocidad de lectura mediante `deque`.

from collections import deque

# Inicializa la cola vacía blindada y preparada para FIFO
cola_comandos = deque()

# Llegan comandos desde el control remoto y se encolan (.append inyecta a la derecha)
cola_comandos.append("ASCENDER_10M")
cola_comandos.append("GIRAR_CAMARA")

# El procesador extrae y ejecuta el comando MÁS VIEJO primero (Saca por la izquierda extrema)
comando_ejecutado = cola_comandos.popleft() 
print(f"Procesador central ejecutando: {comando_ejecutado}") # Imprime ASCENDER_10M

La Armadura Final: Control de Excepciones `Try / Except`

Términos Técnicos:

  • Excepción (Runtime Error): Un evento anómalo o falla crítica que interrumpe la ejecución normal del software mientras el procesador está corriendo. (Ej. División por cero, archivos no encontrados, o cables de sensor arrancados que envían variables vacías). En C esto causaba un temible "SegFault".
  • Manejador de Bloques try / except: En lugar de dejar que el programa implosione y el dron caiga a tierra, tú "intentas" (try) correr el bloque de riesgo. Si explota un error interno, tu bloque "except" atrapa matemáticamente esa falla antes de que colapse el proceso madre y ejecuta un protocolo alterno de contingencia limpia.
  • Cláusula finally: Segmento que se adosa al final del bloque protector. Su contenido se va a ejecutar obligatoria e incondicionalmente, no importa si el bloque try fue exitoso, o si desencadenó la explosión del código en la rama except. Perfecto para cerrar puertos de conexión con antenas e impedir fugas de memoria RAM.

Lógica y Ejemplo Resuelto:

Protegiendo algoritmos de matemáticas defectuosas o inputs humanos basura: Evitamos el ValueError fatal.

# Bloque protegido que encapsula el input físico
try:
    # Peligro: Si el usuario teclea texto (ej. "hola"), int() explota
    tiempo_vuelo = int(input("Ingrese tiempo en minutos para calcular consumo:"))
    consumo = 100 / tiempo_vuelo
    print(f"El dron gastará {consumo}% por minuto")

# Trampa 1: El usuario puso un cero (100 / 0 no existe en matemáticas)
except ZeroDivisionError:
    print("ERROR: El tiempo no puede ser cero. Redirigiendo cálculo...")

# Trampa 2: El usuario escribió letras (falla el casting de int())
except ValueError:
    print("ERROR: Ingresaste texto y el sistema requería números crudos.")

# Ejecución obligatoria
finally:
    print("Liberando socket del sensor y cerrando conexión.")

Taxonomía Resumen de Colecciones Nativas

1. Listas [ ]

Secuencias dinámicas y mutables (editables en runtime). Utilizan mucha memoria pero son muy flexibles.

2. Tuplas ( )

Secuencias inmutables (solo lectura). Extremadamente rápidas en lectura. Ideales para variables críticas.

3. Diccionarios { }

Pares Clave:Valor. La estructura principal para bases de datos NoSQL y para configurar objetos de software JSON.
