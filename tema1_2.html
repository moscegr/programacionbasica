Estructuras de Control en Python

Dotaremos a nuestros programas de toma de decisiones e iteraciones. En Python, la indentación (espacios al inicio de la línea) es OBLIGATORIA para definir bloques de código, a diferencia de las llaves {} de C.

Condicionales

Reemplazamos el switch de C usando if, elif y else.

if bateria > 50:
    print("Misión normal")
elif bateria > 20:
    print("Volver a base")
else:
    print("Aterrizaje emergencia")

Ciclos (Loops)

En Python usamos while y un ciclo for que es mucho más poderoso para recorrer elementos.

# Bucle While
while volando:
    leer_sensores()

# Bucle For (Rango de 1 a 5)
for i in range(1, 6):
    print(f"Punto {i} alcanzado")

Control de Ciclos Avanzado (Break y Continue)

En un flujo de software robótico real (como el de un dron), el terreno y los sensores dictan cambios abruptos. A veces necesitamos alterar el flujo de un bucle desde su interior. Para esto usamos las sentencias reservadas break (rompe y finaliza el ciclo por completo, ideal para salidas de emergencia) y continue (ignora la iteración actual y pasa a la siguiente lectura iterativa).

Sentencia Break:

Abortar misión 
for altitud in range(0, 1000, 10):
    # Monitoreo en tiempo real
    if sensor_viento_fuerte == True:
        print("Alerta crítica.")
        break # Destruye el bucle FOR
    print(f"Avanzando: {altitud}m")

Sentencia Continue:

Omitir iteración 
for sector in sectores_mapeo:
    # Evaluación de permisos
    if sector == "Zona Militar":
        print("Evadiendo sector...")
        continue # Salta al sig. sector
    print("Fotografiando terreno")
