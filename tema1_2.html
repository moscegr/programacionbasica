Estructuras de Control de Flujo

Dotaremos a nuestros programas de "Inteligencia". La capacidad de tomar decisiones basadas en condiciones cambiantes y de repetir acciones en bucle. Es aquí donde la automatización del hardware realmente toma forma.

Regla de Oro: La Indentación (Sangría)

A diferencia de Lenguaje C donde agrupamos el código dentro de llaves {}, en Python los bloques de código pertenecientes a un if, while o for se delimitan exclusivamente por espacios en blanco al inicio de la línea (generalmente 4 espacios o 1 tabulador). Si fallas en este espaciado, el programa crasheará instantáneamente con un IndentationError.

Condicionales (if, elif, else)

Términos Técnicos:

  • Bifurcación: Momento exacto en el que el flujo lineal del software se divide en diferentes "caminos" según la evaluación (True/False) de una variable.
  • Bloque de código (Suite): Líneas de código agrupadas por el mismo nivel de indentación que se ejecutan juntas si el condicional asociado es verdadero.
  • Switch/Case: Estructura clásica en C. En Python, históricamente se reemplaza anidando múltiples elif (Else-If) secuencialmente para evaluar múltiples posibilidades.

Lógica y Ejemplo Resuelto:

Asistente de Altitud de Vuelo Legal: La normativa prohíbe volar drones a más de 120 metros de altitud.

altitud_actual = 145.0

if altitud_actual > 120.0:
    # Este bloque tiene 4 espacios de indentación
    print("ALERTA: Violación de espacio aéreo. Descendiendo.")
elif altitud_actual == 120.0:
    print("ADVERTENCIA: Límite legal alcanzado.")
else:
    print("Altitud dentro de parámetros normales.")

Batería de video crítica". Si es falso, el código simplemente debe terminar sin imprimir nada (no pongas else).
  2. Geofencing Básico (IF/ELSE): Pide la latitud actual por consola. Si la latitud es exactamente igual a la de un aeropuerto cercano (ej. 19.43), imprime "Bloqueo de motores activado (Geofencing)". Si es cualquier otra (ELSE), imprime "Motores armados".
  3. Categorización de Viento (ELIF): Escribe un script que reciba la velocidad del viento (m/s). Si es mayor a 15: "Imposible volar, huracán". Elif mayor a 8: "Vuelo con precaución, usar modo Sport". Else: "Viento en calma, óptimo para fotos".
  4. Chequeo Secuencial Anidado: Crea un bloque de seguridad anidado. Primer IF: verifica si hay conexión GPS. Solo si es True, entra a un segundo IF interno que verifique si hay más de 8 satélites conectados. Si ambos se cumplen, imprime "Misión autónoma lista". Ciclos While y Evaluación Continua

Términos Técnicos:

  • Bucle (Loop) While: Estructura que repite un bloque de código mientras una condición relacional siga siendo True. Al momento en que la condición se vuelve False, el bucle se destruye y el programa continúa.
  • Iteración: Cada vuelta o repetición individual que ejecuta el bucle de inicio a fin.
  • Bucle Infinito: Falla lógica donde la variable que se evalúa en el while jamás cambia su estado a falso. El CPU se queda atrapado procesando la misma instrucción eternamente, colapsando el software.

Lógica y Ejemplo Resuelto:

Drenaje de Batería Simulado: Un script que monitorea la caída de energía vuelta por vuelta.

bateria = 100

# Se repetirá eternamente MIENTRAS bateria sea mayor a 0
while bateria > 0:
    print(f"Nivel de energía: {bateria}%")
    # CRÍTICO: Modificar la variable de control o será infinito
    bateria = bateria - 20  # Resta 20 en cada iteración

print("El dron se ha apagado.")

Ciclo For y Control de Interrupciones Avanzado

Términos Técnicos:

  • Bucle For (Foreach iterativo): En Python, el bucle For es infinitamente más poderoso que en C. No se usa para contar números rígidamente, sino para "recorrer" o visitar uno a uno los elementos de una colección de datos (como letras en un texto, o coordenadas en un rango).
  • Sentencia break: Una salida de emergencia. Si se activa dentro de un bucle (ya sea for o while), destruye inmediatamente el ciclo, sin importar cuántas iteraciones faltaban.
  • Sentencia continue: Una herramienta de evasión. Cancela solamente la iteración actual, saltándose el código que le sigue abajo, y brinca directamente a evaluar el siguiente elemento del bucle.

Lógica y Ejemplo Resuelto:

Recorriendo Zonas de Rastreo (Waypoints) con `continue`: El dron debe escanear sectores, pero debe saltarse las Zonas Militares sin romper toda la misión.

# Usaremos una lista simple para recorrer
sectores = ["Bosque", "Zona Militar", "Río", "Montaña"]

for sector in sectores:
    if sector == "Zona Militar":
        print("Sector restringido detectado. Evadiendo...")
        continue  # Brinca el análisis y pasa directo a 'Río'
    
    print(f"Encendiendo cámara espectral y escaneando: {sector}")
